## Как считали

- Cache hit и платные запросы разведены: cache hit = 0 ₽ и 0 с, считается отдельно.
- Окна:
  - **ALL** — вся база, включая ранние эксперименты и разные версии промптов (51 `config_version`).
  - **CUR** — карточки, созданные с 24.10 14:40 UTC (после salvage). Версии промптов внутри окна менялись, это не один конфиг.
- План на две роли учтён один раз: у второй роли `plan` приходит из кэша (10 cache hit, 0 ₽).
- Неизвестная цена не обнуляется:
  - 4 запроса отменены или оборваны по таймауту, стоимости нет;
  - 3 запроса `request_abandoned` (2 `repair`, 1 `pdf_ocr`) записаны со стоимостью, равной резерву, — 62,39 ₽. Это оценка резерва, не факт; в итоги не входит.
- Платные запросы включают ошибочные: за них тоже заплачено.
- Исходные строки и скрипт — в [docs/eval/](eval/). Каждое число ниже воспроизводится командой `python -I docs/eval/analyze.py`.
