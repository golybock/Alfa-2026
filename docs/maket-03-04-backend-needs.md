# Макеты 03 (лента) и 04 (карточка): что нужно от backend

Состояние на 24.10.2026. Из первоначального списка Артём закрыл четыре пункта (PR #20 и #21). Остался один.

## Закрыто и подключено на фронте

| Что | Откуда берётся | Где показано |
| --- | --- | --- |
| Метка «Риск / Возможность / Неопределённость» | `InsightDto.direction` | Шапка карточки |
| Период анализа | `news_period_from` и `news_period_to` | Шапка карточки, «Период анализа: 15–21 октября 2026» |
| Признаки компании | `company_traits[].label` (включая «Группа · 26,0 млрд ₽») | Полоска в блоке «Почему это касается вас». Если `company_traits` нет, полоска строится из `relevance.reasons[].label` |
| Дата данных банка | `bank_data_as_of` | Блок «На чём основан вывод». Если поля нет, берётся из доказательств `bank_research`, иначе «Данные банка: данных нет» |

## Осталось: страница «Добавить материал»

Страница сделана на фронте (`/materials`, кнопка в шапке ленты). Загрузка PDF с индикатором (загрузка файла в процентах, затем «Распознаём страницы: N из M») работает, но упирается в следующее.

| № | Что нужно | Что есть сейчас |
| --- | --- | --- |
| 1 | Открыть загрузку PDF и список документов для демо-пользователей: `POST /admin/documents`, `GET /admin/documents`, `GET /admin/documents/{id}` сейчас только для оператора | Демо-пользователь получает 403, на странице показано «Загрузка PDF доступна оператору». Страница предназначена «для жюри», то есть для обычных учёток |
| 2 | Доступ оператора к странице: у `admin` и `operator` нет компаний, а оболочка банка требует выбранную компанию, поэтому оператор не может открыть `/materials` | Страница недоступна ни обычному пользователю (403 при загрузке), ни оператору (нет оболочки). Нужно решение: открыть загрузку демо-пользователям (п. 1) или пускать оператора в оболочку без компании |
| 3 | Ручная новость по ссылке: endpoint `POST /admin/news` и обработчик `CollectManualNews` (D17) | В коде есть только `ManualNewsRequest` и `CollectManualNewsJob`, обработчика нет, задание завершится как `not_implemented`. Блок «Ссылка на новость» на странице показан, но неактивен («Добавление по ссылке появится позже») |
| 4 | Фильтр «Ваши загрузки»: в `DocumentSummaryDto` нет автора и времени добавления | Список называется «Загруженные материалы» и показывает все документы, включая 9 стартовых |
| 5 | Статус «Ждёт ключа модели» для документов (`llm_key_required`) | В `DocumentSummaryDto` и `DocumentResponse` такого статуса нет, показываются только `queued`, `processing`, `ready`, `partial`, `failed` |

Лимиты на странице указаны по бэкенду: 50 МБ и 50 страниц (в макете было 30 страниц).

## Что сделано только на фронте

- Метка для типа `neutral` называется «Неопределённость» вместо «Нейтрально». В контракте тип остался `neutral`.
- Тема новости в верхней строке превью ленты убрана: в новом макете её нет.
- Блок «Почему показано» убран из карточки, как в макете. Причины отбора остались в панели «Почему я это вижу».
- Подзаголовок шапки карточки собирается из первого утверждения блока «Что произошло» и ссылки на новость из его доказательств.

## Что стоит согласовать

- В блоке «На чём основан вывод» всегда показаны обе строки дисклеймера, как в макете. Раньше вторая («Вывод ИИ не является позицией Альфа-Банка») показывалась только при `bank_view.status = not_found`.
- Номер места (`rank`) в шапке карточки в новом макете отсутствует, он остался только в панели «Почему я это вижу».
