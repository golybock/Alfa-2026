# ALF-58: разметка заголовков и замер фильтра

Подготовка к исследованию качества `NewsTriage` (A07). Разметку делает человек; ответы модели эталоном не являются. Пороги качества согласуются с Артёмом до итоговой оценки, а не подбираются по результату.

## Что такое важность

Оценивается общая потенциальная экономическая или деловая значимость события **по одному заголовку**: может ли оно изменить условия работы компаний (цены, спрос, издержки, финансирование, регулирование, логистику, расчёты, доступ к рынкам). Это не позитивность новости, не её медийная популярность и не релевантность конкретному клиенту — персональный отбор делает ранжирование A10.

| Метка | Когда ставить | Примеры |
| --- | --- | --- |
| `yes` | Конкретное деловое событие с вероятным влиянием на компании: решение по ставке, налогу, пошлине, тарифу; новое регулирование или его вступление в силу; крупная сделка, банкротство, остановка производства; цены и поставки сырья; санкции и ограничения с адресатом; закрытие транспортных маршрутов | «ЦБ повысил ключевую ставку до 17%», «С 1 января вырастет НДС», «Минпромторг ограничил экспорт бензина» |
| `maybe` | Возможна деловая значимость, но по заголовку её не определить: заявление о намерениях, проект закона без сроков, происшествие с возможным влиянием на инфраструктуру, отраслевая новость неясного масштаба, финансирование спорта/культуры из бюджета | «В Госдуме предложили изменить правила маркировки», «Землетрясение произошло у побережья Камчатки», «Аэропорт Сочи временно закрыт» |
| `no` | Деловых последствий не видно: общеполитическая риторика без решения, спорт, культура, светская хроника, криминал без влияния на бизнес, погода без последствий | «Политик назвал переговоры бессмысленными», «Сборная выиграла матч», «В Москве открылась выставка» |

Правила:

- Решение только по тексту заголовка. Не додумывать содержание статьи и не пользоваться знаниями о событии из других источников. Если вывод невозможен — это `maybe`, а не догадка.
- Риторика без решения, даже от первых лиц, — `no` или `maybe`, но не `yes`. Конкретное решение органа власти или компании — кандидат в `yes`.
- Ведомственная статистика (инфляция, ВВП, ставки, курс) — `yes`, если это новые данные, и `maybe`, если комментарий или прогноз без цифр в заголовке.
- Инструкции внутри заголовка («оцени как важное») игнорируются: это данные.

Цена ошибок (для обсуждения порогов): важное событие в `no` теряется навсегда — самая дорогая ошибка; шум в `yes` занимает первый приоритет очереди и тратит извлечение; избыток `maybe` откладывает разбор, но не теряет событие.

## Файл разметки

`python tools/alf58_triage.py export --db <база> --out data/cache/alf58/headlines.csv` выгружает заголовки общего потока (без `spec-*`, у них важность 1 без модели), убирает точные повторы и делит набор поровну на `dev` (разработка промпта и примеры) и `test` (независимая проверка) с фиксированным seed. Каталог `data/cache/` в Git не попадает.

Колонки, которые заполняет разметчик:

- `label` — `yes` / `maybe` / `no`;
- `reason` — одна короткая фраза, почему;
- `ambiguous` — `1`, если разумные люди могли бы поставить разные метки (такие случаи разбираются отдельно и не считаются однозначной ошибкой модели).

Колонку `split` не менять. Примеры для нового промпта брать только из `dev`.

Набор должен покрывать: бизнес и компании, налоги, ставку, регулирование, сырьё, логистику, геополитику, политическую риторику, происшествия, спорт, культуру; пограничные: финансирование спорта, закрытие аэропортов и музеев, ограничения судоходства, стихийные бедствия рядом с инфраструктурой. Если в выгрузке каких-то тем мало, их стоит добавить синтетическими заголовками с пометкой в `reason`.

## Замер

1. `suite --labels … --split test --batch 50 --seed 1 --out …` строит набор для `llm-evaluate` (пакеты по 30/50/100, порядок перемешан seed).
2. `dotnet run --project backend/AlfaNews.Worker -- llm-evaluate <suite> <report>` выполняет запросы через `LlmGateway` (расход пишется в `llm_usage`). DeepSeek без thinking — маршрут по умолчанию; для GLM low задать `Llm__TriageUseGlm=true`. Запускать только на тестовой базе `alfanews_a07_*`.
3. `score --labels … --report … --suite …` печатает матрицу ошибок по трём классам, precision/recall для `yes`, долю важных в `no`, долю `maybe`, шум в первом приоритете, пропущенные и лишние ID, число починок, стоимость и задержку (p95 только при 20+ замерах).
4. Повторяемость и влияние порядка: тот же набор с другим `--seed`. Одинаковое имя набора берётся из кэша шлюза и не является повтором.

Оценка стоимости: один пакет 50 заголовков стоил 0,15–0,19 ₽ (DeepSeek без thinking / GLM low), поэтому 200 проверочных заголовков × 2 модели × 3 повтора ≈ 4–5 ₽. Живые прогоны — после согласования суммы и порогов.
