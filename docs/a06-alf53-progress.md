# ALF-45 / ALF-53: прогресс на 22.10.2026

Работа возобновлена по команде пользователя. Изменения оставлены незакоммиченными в текущей ветке. Коммиты, ветки, PR и push запрещены без отдельной просьбы.

## Принятые решения

- Общий бюджет — 500 ₽, сброс в 03:00 МСК. Валюта usage.cost — рубли.
- Тестовый потолок увеличен пользователем с 50 до суммарных 150 ₽. История расходов не удаляется; неизвестная стоимость сохраняет резерв.
- Миграция request_key / reserved_cost_rub и индекс согласованы и применены. API/Worker автоматически накатывают миграции при запуске; Compose migrate сохранён.
- По последнему решению GLM OCR/Critic запрашивает low вместо high. Уровень задаётся LLM_GLM_REASONING_LEVEL=low. Thinking у GLM-5.3-Flash принудительный; выключателя нет.
- DeepSeek thinking переключается через LLM_DEEPSEEK_THINKING_ENABLED=true|false. В текущий .env добавлен true. Для изменения режима требуется перезапуск Worker.
- В .env добавлены только эти две несекретные настройки; остальные строки сохранены. Значения и секреты не выводились.
- По просьбе пользователя решение low и переключатель DeepSeek записаны в описания ALF-45 и ALF-53. Статусы задач не менялись.

## Реализация

- Core/Configuration/LocalEnvironment.cs автоматически загружает ближайший родительский .env; env процесса имеет приоритет. Сопоставляются LLM/POSTGRES/FEED aliases; Npgsql корректно собирает локальную строку подключения. API, Worker и design-time EF используют загрузчик.
- Core/Llm содержит LlmGateway, OpenAiApiClient, MockLlmClient, каталог файловых промптов, строгую JSON Schema/DTO и предметную валидацию, кэш, бюджет и учёт каждой попытки.
- DeepSeek обслуживает новости/план/черновик/починку/чат/gate. GLM — OCR/критик. Потолки 32000; чат/gate и их починка 8000. Для живых тестов использовался уменьшенный потолок 12000, для РБК — 8000.
- По умолчанию включён mock. Живые вызовы тестов включались переменными процесса, .env ради этого не переключался.
- Полные JSON Schema отправляются в response_format=json_schema со strict=true и остаются в системных правилах. DeepSeek/GLM приняли $ref/$defs и вернули структурно валидный JSON. Это доказывает приём параметра, но не внутреннюю реализацию constrained decoding. Локальная проверка обязательна.
- Кэш различает модель, reasoning/его включение, шаблоны, схемы, версии правил/входа/конфига, изображения и mock/live. Успешная починка кэшируется также для исходной операции. Попадание в кэш не требует сети/ключа/свободного бюджета.
- Перед HTTP сохраняются попытка и консервативный резерв. После HTTP usage.cost заменяет его при расчёте остатка; заголовок x-litellm-response-cost — запасной источник. Неизвестная цена не превращается в ноль.
- Максимум четыре HTTP, два технических повтора 2/5 секунд, одна общая починка. Критик — один HTTP на ключ операции, без повторов и после рестарта. 401/403 блокирует новые вызовы до рестарта; length терминальный.
- Один процесс Worker допускает два HTTP одновременно. Межпроцессной блокировки резерва и общего HTTP-ограничителя пока нет; MVP рассчитан на один Worker.
- Caller может передать общий RunId; его жизненным циклом управляет caller. Отдельные вызовы создают свой agent_run, связанный с background_job.
- Команда Worker: llm-evaluate <cases.json> <report.json> [case1,case2]. Отчёт содержит кандидаты, ошибки, токены, деньги и длительность без ключей, системных промптов и скрытых рассуждений. Фильтр сохраняет InputVersion исходного набора.
- EF migration 20261022155147_LlmAttemptReservations, сущность/конфигурация, snapshot и contracts/database.sql синхронизированы. JSON-контракты не менялись.

## Промпты и найденные дефекты

Восемь английских пар приняты из Desktop/Alfa-2026/llm-prompts-en в Core/Prompts. Схемы копируются при build/publish из contracts/schemas; независимой исходной копии нет. Пакет 2.0.3: NewsExtract 2.0.1, PdfOcr 2.0.2, Draft/Critic 2.0.1, остальные 2.0.0. В manifest 25 нормализованных SHA-256.

- GLM возвращал Markdown fences: PDF-промпт теперь явно требует raw JSON.
- Новость возвращала название страны вместо кода: News/PDF явно выбирают code, ключ словаря или строку, а не description.
- Проверка приблизительности ошибочно различала «По» и «по»: исправлена без ослабления обязательной пометки.
- По просьбе пользователя сравнение цитат нормализует Unicode whitespace/NBSP/переносы/табуляцию и игнорирует U+200B, U+FEFF, U+2060, U+00AD. Буквы, цифры, пунктуация и границы слов всё ещё должны совпадать. Источник и ответ не переписываются.
- forecast:null теперь считается отсутствием прогноза; непустой объект при выключенной функции запрещён. Раньше null вызывал лишнюю починку.
- Draft смешивал сентябрьское ожидание банка с октябрьским решением, в том числе в заголовке. Draft/Critic теперь явно запрещают такое сопоставление. GLM на реально ошибочном черновике нашёл temporal_mismatch в C6 и связал его с заголовком/последствием/действием.
- Схемная валидность не доказывает экономический смысл: в синтетическом payment-контексте не названа сама отрасль доли 24%, встречается неоднозначная её трактовка и внутренние названия полей в тексте. Не считать такие карточки автоматически пригодными для публикации.
- OCR графиков местами путает серии; все числа графиков остаются запрещёнными для количественных выводов до ручной сверки. Производственные обработчики A07–A13 не реализованы в этой задаче.
